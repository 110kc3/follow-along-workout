# follow-along-workout

Automated short-form daily workout brand. One 20–45 s vertical video per day:
LLM-composed workout from an allowlisted exercise pool → Remotion template
render → Telegram approval → auto-post to YouTube Shorts (IG/TikTok manual
initially). Orchestrated by the n8n + LiteLLM stack already running on the Pi.
